# Calculator

Final project of [The Odin Project – Foundations](https://www.theodinproject.com/lessons/foundations-calculator).

**Live demo:** https://ayxan1110.github.io/odin-calculator/

## Features
- Add, subtract, multiply and divide with `operate(operator, a, b)`
- Evaluates one pair at a time: `12 + 7 - 1` shows `19` before the minus
- Rounds long decimals so they fit on the screen
- Shows an error message when you divide by 0
- Extra credit: decimal point, backspace and keyboard support
- No `eval()` is used
